# Swift крок за кроком

Україномовний практичний курс **Swift 6 і розробки для Apple-платформ**. Маршрут побудований так, щоб ти міг почати на Windows, а після придбання MacBook перейти до Xcode та створення нативного застосунку.

## Мета

Підготуватися до самостійної початкової роботи на MacBook: розуміти Swift, користуватися macOS як середовищем розробника, працювати в Xcode, створювати інтерфейси на SwiftUI, зберігати дані, тестувати й налагоджувати застосунок.

Це навчальний маршрут до впевненого старту, а не обіцянка професійного рівня за 12 тижнів.

## Дві частини — один маршрут

| Етап | Коли | Результат |
|---|---|---|
| **I. Фундамент Swift (тижні 1–8)** | Windows / Linux / macOS | Мова, типи, пам'ять, concurrency, пакети, тести та готова логіка навчального трекера |
| **II. Apple-розробка (тижні 9–12)** | Після отримання MacBook | macOS, Xcode, SwiftUI, збереження даних, налагодження й завершений нативний застосунок |

Перші вісім тижнів і консольний проєкт доступні на Windows, Linux та macOS. **Для тижнів 9–12 потрібен Mac**, оскільки Xcode та Apple SDK не є повноцінно доступними на Windows/Linux.

На Windows інтерактивний REPL не підтримується: для окремих файлів використовуй `swiftc`, `swift run` або навчальний PowerShell-скрипт.

## Як проходити курс

- Рекомендований ритм: 5 занять на тиждень, 45–60 хвилин на день. Apple-етап може вимагати більше часу на освоєння Xcode.
- Набирай приклади самостійно, змінюй їх і пояснюй собі результат.
- Не копіюй готове рішення вправи: спочатку спробуй сам, потім проси підказку або рев'ю.
- Фіксуй прогрес Git-комітами та коментарями в Issue.
- Не позначай платформу перевіреною, якщо реально не збирав і не запускав проєкт на ній.

## Принципи

- Пояснення та завдання — українською; API й ідентифікатори — у звичному Swift-стилі англійською.
- Спочатку стандартна бібліотека; залежності додаються лише за потреби.
- Спершу відокремлюй модель і логіку від інтерфейсу, потім підключай SwiftUI.
- Версії Xcode, macOS та SDK не фіксуються назавжди: перед встановленням перевіряй офіційну сумісність зі своєю моделлю Mac.
- Основний інструмент Apple-етапу — Xcode і SwiftUI; UIKit/AppKit вивчай за потреби, не намагаючись охопити всі фреймворки одразу.
