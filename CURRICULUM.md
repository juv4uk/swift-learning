# Навчальний план: Swift → MacBook → Xcode

Курс має дві частини. **Тижні 1–8** можна проходити на Windows, Linux або macOS. **Тижні 9–12** потребують Mac із сумісною версією macOS та Xcode.

Рекомендований темп: 5 занять на тиждень, 45–60 хвилин на день. Для Apple-етапу закладай додатковий час на знайомство з Xcode та інтерфейсом.

## Частина I. Фундамент Swift — тижні 1–8

### Тиждень 1 — мислити типами
- День 1: print, коментарі, let і var.
- День 2: String, Int, Double, Bool, type inference.
- День 3: інтерполяція, арифметика, перетворення типів.
- День 4: if, else, switch.
- День 5: цикли, діапазони, повторення.
- **Результат:** невелика консольна програма без копіювання готового коду.

### Тиждень 2 — функції та дані
- Функції, параметри, зовнішні/внутрішні імена.
- Array, Dictionary, Set.
- Optional, if let, guard let, ??.
- **Результат:** каталог навчальних тем у пам'яті.

### Тиждень 3 — власні типи
- struct, class, enum, init.
- Stored/computed properties, методи, mutating.
- Value semantics та reference semantics.
- **Результат:** модель навчального запису або книги.

### Тиждень 4 — протоколи та узагальнення
- protocol, conformance, composition.
- extension, generics, where.
- Equatable, Hashable, Identifiable.
- **Результат:** кілька типів зі спільною поведінкою.

### Тиждень 5 — функції як значення та помилки
- Closures, map, filter, sorted, reduce.
- throws, do-catch, Result.
- Валідація та передбачувана обробка помилок.
- **Результат:** безпечна обробка списку даних.

### Тиждень 6 — пам'ять і конкурентність
- ARC, strong/weak, цикли посилань.
- async/await, Task, cancellation.
- actor та ізоляція стану.
- **Результат:** асинхронна операція з безпечним станом.

### Тиждень 7 — інструменти розробника
- Swift Package Manager, targets, products, dependencies.
- Модулі й access control.
- Codable, JSON, URL/FileManager.
- XCTest, Git, README, відтворювана збірка.
- **Результат:** пакет із тестами та JSON round-trip.

### Тиждень 8 — Study Tracker CLI
Створи кросплатформний консольний трекер:
- StudyItem з UUID, назвою, статусом і датою.
- StudyStatus як enum.
- Додавання, зміна статусу, пошук, фільтрація.
- JSON persistence через Foundation.
- Обробка відсутнього/пошкодженого файла.
- Тести моделі, логіки та сховища.
- README з командами запуску.

**Контрольна точка перед Apple-етапом:** `swift build`, `swift test`, `swift run` успішні на твоїй поточній ОС; ти можеш пояснити модель, логіку, сховище й тести. Дивись [Issue #8](https://github.com/juv4uk/swift-learning/issues/8).

## Частина II. Розробка для Apple — тижні 9–12

### Тиждень 9 — Mac як робоче середовище та Xcode
- День 1: Finder, файлові шляхи, розширення, дозволи, встановлення застосунків і оновлення macOS.
- День 2: Terminal, базові shell-команди, Git, SSH-ключі та робочі каталоги.
- День 3: перевір сумісність моделі Mac, macOS та стабільного Xcode; встанови Xcode і дочекайся компонентів.
- День 4: розбери Xcode — workspace/project, targets, schemes, navigator, inspector, editor, toolbar.
- День 5: створи macOS App-проєкт SwiftUI; запусти його на Mac і в доступному Simulator; постав breakpoint, подивись variables і console.
- **Результат:** можеш створити, зібрати, запустити й налагодити порожній застосунок.

### Тиждень 10 — SwiftUI та інтерфейс
- День 1: App entry point, Scene, View, body, modifiers, Preview.
- День 2: VStack, HStack, ZStack, spacing, padding, frame, адаптивне компонування.
- День 3: @State та @Binding; джерело істини й передавання даних.
- День 4: List, ForEach, NavigationSplitView/NavigationStack, toolbar.
- День 5: Form, TextField, Picker, кнопки, sheets, alerts, валідація.
- **Результат:** інтерфейс Study Tracker із переліком, деталями та формою редагування.

### Тиждень 11 — архітектура, дані та асинхронність
- День 1: відокремлення моделей і бізнес-логіки від SwiftUI View; межі відповідальності.
- День 2: SwiftData — модель, ModelContainer, запити та збереження між запусками.
- День 3: стани завантаження, порожній стан, помилка; Task і async/await у UI.
- День 4: URLSession, HTTP-запит до відкритого навчального API, Codable, перевірка помилок і відсутності мережі.
- День 5: інтеграція локального трекера; не зберігай секрети/API-ключі у вихідному коді.
- **Результат:** дані переживають перезапуск, UI не блокується під час асинхронної роботи, помилки пояснені користувачу.

### Тиждень 12 — якість, налагодження та завершення
- День 1: Xcode Test Navigator; unit-тести логіки та тестування критичних сценаріїв.
- День 2: breakpoints, LLDB basics, console, перегляд помилок і стеку викликів.
- День 3: доступність — VoiceOver labels, Dynamic Type, клавіатурна навігація, контраст і зрозумілі підписи.
- День 4: Git, конфігурації Debug/Release, signing basics, capabilities, sandbox і дозволи; розуміння різниці між Run, Archive та Export.
- День 5: чиста збірка, фінальні тести, README, скриншоти та демонстрація застосунку.
- **Результат:** завершений навчальний macOS-застосунок, який можна зібрати повторно та показати іншій людині.

## Фінальний проєкт — Study Tracker для macOS

Обов'язкові можливості:
- список навчальних тем із пошуком/фільтрацією;
- додавання, редагування, зміна статусу та видалення;
- детальний перегляд запису;
- локальне збереження через SwiftData;
- зрозумілі порожні, помилкові та завантажувальні стани;
- доступність основних елементів;
- unit-тести для бізнес-логіки;
- README із вимогами, запуском, архітектурою та відомими обмеженнями.

Додатково, якщо основне готове: синхронізація з API, iPhone Simulator або окрема iOS-ціль. Не розширюй проєкт, поки базовий macOS-сценарій не працює надійно.

## Контроль готовності до MacBook

- [ ] Розумію Swift на рівні, достатньому для читання незнайомого коду.
- [ ] Вмію користуватися Terminal, Git і файловою системою macOS.
- [ ] Можу створити Xcode-проєкт і пояснити його структуру.
- [ ] Можу побудувати SwiftUI-інтерфейс зі станом, списками, формами та навігацією.
- [ ] Можу зберегти дані й обробити помилки.
- [ ] Можу запускати тести, ставити breakpoints і читати помилки.
- [ ] Розумію базові принципи доступності, signing та збірки.

## Важлива примітка щодо версій

Не встановлюй Xcode за застарілим номером із цього курсу. Перед придбанням Mac і перед встановленням Xcode перевір точну сумісність конкретної моделі Mac, її версії macOS та поточного стабільного Xcode на [офіційній сторінці системних вимог](https://developer.apple.com/xcode/system-requirements/). Не використовуй beta як основне навчальне середовище без окремої причини.
