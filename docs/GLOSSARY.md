# Словник Swift для початківця

Це не довідник усієї мови. Тут зібрані слова, які найчастіше зустрінеш у перших уроках.

## Значення та типи

**Константа (`let`)** — ім’я для значення, яке не плануємо змінювати.

```swift
let courseName = "Swift"
```

**Змінна (`var`)** — ім’я для значення, яке можна змінити.

```swift
var completedLessons = 0
completedLessons += 1
```

**Тип** описує, які дані зберігає значення і що з ними можна робити. Наприклад, `String` — текст, `Int` — ціле число, `Double` — число з дробовою частиною, а `Bool` — `true` або `false`.

**Type inference** — автоматичне визначення типу за початковим значенням. У `let age = 18` Swift сам визначає `Int`. Тип можна вказати явно: `let age: Int = 18`.

**Інтерполяція рядка** вставляє значення в текст за допомогою `\(expression)`.

```swift
let name = "Оля"
print("Привіт, \(name)!")
```

## Керування виконанням

**Умова** (`if`, `else`, `switch`) обирає, який код виконати залежно від значення.

**Цикл** повторює код. `for item in items` проходить елементи колекції, а `while` повторює код, поки умова істинна.

**Функція** — іменований блок коду, який виконує одну задачу. Параметри — вхідні дані функції, результат після `->` — її вихід.

```swift
func greet(name: String) -> String {
    "Привіт, \(name)!"
}
```

## Дані та власні типи

**Array** — впорядкований список значень одного типу: `["Swift", "Git"]`.

**Dictionary** — колекція пар ключ-значення: `["name": "Оля"]`.

**Set** — набір унікальних значень без гарантованого порядку.

**Optional** — значення, якого може не бути. Тип `String?` може містити рядок або `nil`.

```swift
let nickname: String? = nil
let shownName = nickname ?? "Гість"
```

`if let` і `guard let` безпечно дістають значення з optional. Не використовуй `!`, доки не можеш пояснити, чому значення точно існує.

**`struct`** — тип-значення для опису сутності. Копія структури має власне значення.

**`class`** — reference type. Дві змінні можуть посилатися на один об’єкт.

**`enum`** — тип із кінцевим набором варіантів, наприклад `.planned`, `.inProgress`, `.done`.

**Властивість** — дані всередині типу. **Метод** — функція всередині типу.

## Спільний і безпечний код

**Protocol** описує вимоги до типу. Тип, який відповідає протоколу, називається його conforming type.

**Extension** додає можливості до наявного типу, не змінюючи його основного оголошення.

**Generic** дає змогу написати код, який працює з різними типами, зберігаючи перевірку типів.

**Closure** — безіменний блок коду, який можна зберегти у змінній або передати у функцію.

```swift
let doubled = [1, 2, 3].map { number in
    number * 2
}
```

**Error** — опис проблеми, яку функція може повернути. `throws` позначає функцію, що може завершитися помилкою, а `do-catch` її обробляє.

## Проєкт і перевірка

**Модуль** — частина коду, яку можна імпортувати. **Target** — продукт або набір файлів, який збирає Swift Package Manager. **Dependency** — зовнішній код, від якого залежить проєкт.

**Компіляція** — перетворення вихідного коду на виконувану програму. Компілятор також перевіряє типи й синтаксис.

**Unit-тест** — маленька автоматична перевірка однієї частини логіки. Хороший тест має зрозумілу умову, дію та очікуваний результат.

**JSON** — текстовий формат для обміну та збереження структурованих даних. `Codable` допомагає кодувати Swift-типи в JSON і декодувати JSON назад.

**CLI** (command-line interface) — програма, якою керують командами в терміналі.

## Пам’ять і асинхронність

**Value semantics** означає, що присвоєння створює окреме значення. Типовий приклад — `struct`.

**Reference semantics** означає, що присвоєння копіює посилання на той самий об’єкт. Типовий приклад — `class`.

**ARC** автоматично керує часом життя об’єктів-класів. `weak` допомагає уникати циклів посилань.

**Асинхронний код** може чекати на повільну операцію, не блокуючи всю програму. `async` позначає таку функцію, `await` — місце очікування результату.

**Actor** захищає змінюваний стан, коли код працює паралельно.

## Apple-етап

**Xcode** — IDE Apple: редактор коду, збірка, тести, налагодження та запуск застосунків.

**SwiftUI View** описує частину інтерфейсу. **State** — дані, від яких залежить інтерфейс. Коли state змінюється, SwiftUI оновлює відповідний View.

**Simulator** запускає застосунок у віртуальному пристрої. Він не замінює перевірку на реальному пристрої в усіх сценаріях.

**Breakpoint** тимчасово зупиняє програму в конкретному рядку, щоб подивитися значення змінних і хід виконання.
