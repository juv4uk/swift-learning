# Старт із нуля

Цей гід допоможе почати курс, якщо ти раніше не писав(-ла) код або не знаєш, як працюють термінал, Git і компілятор.

## Що ти вивчатимеш

**Swift** — мова програмування від Apple. Нею пишуть логіку застосунків: роботу з даними, правилами, мережевими запитами та інтерфейсом.

**SwiftUI** — фреймворк Apple для створення інтерфейсів із Swift. Він потрібен на етапі після отримання Mac. Перші вісім тижнів можна проходити без Mac: вони присвячені самій мові та консольному проєкту.

**Термінал** — програма, у якій команди вводять текстом. **Компілятор** перетворює Swift-код у програму, яку може запустити комп’ютер. **Swift Package Manager** збирає проєкт, запускає його та виконує тести.

**Git** зберігає історію змін. **GitHub** — сайт, де можна зберігати Git-репозиторії та показувати свій код.

## Що потрібно до початку

Тобі потрібні:

- комп’ютер із Windows, Linux або macOS;
- стабільний Swift toolchain;
- Git;
- редактор коду, наприклад Visual Studio Code;
- 45–60 хвилин на одне заняття.

Mac не потрібен для перших восьми тижнів. Mac знадобиться тоді, коли ти перейдеш до Xcode, SwiftUI та Apple SDK. Деталі встановлення шукай в [уроці 0](../lessons/00-platform-setup.md) та інструкції для своєї ОС:

- [Windows](SETUP-WINDOWS.md)
- [Linux](SETUP-LINUX.md)
- [macOS](SETUP-MACOS.md)

## Перше заняття за 30 хвилин

### Крок 1. Відкрий термінал

У Windows відкрий PowerShell. У Linux або macOS відкрий Terminal. Перевір, що Swift доступний:

```text
swift --version
swiftc --version
swift package --version
```

Якщо команда `swift` не знайдена, не переходь далі: спочатку заверш встановлення за інструкцією для своєї платформи.

### Крок 2. Завантаж репозиторій

```bash
git clone https://github.com/juv4uk/swift-learning.git
cd swift-learning
```

У PowerShell замість `cd` можна використати `Set-Location .\swift-learning`.

### Крок 3. Запусти першу програму

Windows / PowerShell:

```powershell
.\scripts\run-example.ps1 01-hello
```

Linux / macOS:

```bash
./scripts/run-example.sh 01-hello
```

Ти побачиш текст, який надрукувала Swift-програма. Скрипт компілює файл і запускає результат. Це відрізняється від простого відкриття `.swift`-файла: код потрібно перевірити компілятором.

### Крок 4. Подивись код і зміни його

Відкрий [`examples/01-hello/main.swift`](../examples/01-hello/main.swift). Зміни текст усередині `print`, збережи файл і знову запусти команду. Навмисна маленька зміна допомагає зрозуміти зв’язок між кодом і результатом.

Після цього відкрий [урок 1](../lessons/01-basics.md) і виконай вправи без копіювання готового розв’язку.

### Крок 5. Перевір увесь пакет

```text
swift build
swift run
swift test
```

- `swift build` перевіряє, чи можна зібрати проєкт.
- `swift run` запускає основну CLI-програму.
- `swift test` виконує автоматичні тести.

Якщо всі три команди завершилися успішно, перше налаштування готове.

## Як проходити один урок

Не намагайся лише прочитати матеріал. Для кожного уроку використовуй один і той самий цикл:

1. Прочитай мету та ключові поняття.
2. Запусти наявний приклад.
3. Передрукуй його самостійно, не копіюючи рядок за рядком.
4. Зміни одне значення та спрогнозуй результат.
5. Виконай вправу.
6. Навмисно зламай маленьку частину коду й прочитай помилку компілятора.
7. Запиши своїми словами, що нового зрозумів(-ла).
8. Збережи результат окремим Git-комітом.

Помилка — це не провал. На початку важливо навчитися знайти рядок із проблемою, зрозуміти повідомлення та перевірити виправлення.

## Якщо щось не працює

**`swift` не знайдена.** Закрий і знову відкрий термінал після встановлення toolchain. Якщо це не допомогло, перевір PATH та інструкцію для своєї ОС.

**PowerShell не запускає `.ps1`.** Дозволь скрипти лише в поточному вікні:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**Помилка під час `swift build`.** Прочитай першу помилку у виводі, а не останній рядок. Перевір, що ти перебуваєш у корені репозиторію — там є `Package.swift`.

**Не знаєш, що означає повідомлення.** Скопіюй назву помилки, номер рядка та невеликий фрагмент коду. Не публікуй паролі, токени або приватні файли. Для нотаток використовуй [`NOTES.md`](../NOTES.md), а для запитань — GitHub Issues репозиторію.

**Ти працюєш на Windows.** Це нормально: інтерактивний REPL може бути недоступний, але курс розрахований на `swiftc`, `swift run` і `swift test`. Не намагайся встановити Xcode на Windows — Apple-етап потребує Mac.

## Коли переходити далі

Переходь до наступного уроку, коли можеш без підглядання пояснити головну ідею поточного, запустити приклад і виконати хоча б основну вправу. Не потрібно пам’ятати кожен метод напам’ять. Потрібно вміти читати код, шукати відповідний приклад у документації та поступово виправляти помилки.

Після тижня 8 перевір контрольну точку в [CURRICULUM.md](../CURRICULUM.md). До Apple-етапу переходь лише після того, як `swift build`, `swift test` і `swift run` працюють, а ти можеш пояснити модель, логіку, сховище та тести свого Study Tracker.
