# Інструкції для AI-агентів

- Пояснюй навчальний матеріал українською мовою.
- Використовуй ідіоматичний Swift і зрозумілі англомовні ідентифікатори в коді.
- Цільовий toolchain курсу: Swift 6.4+; Package.swift використовує tools-version 6.0 для сумісності.
- Не додавай сторонні пакети без необхідності.
- Кожен приклад має бути самодостатнім і містити команду запуску.
- Не замінюй реальні результати тестів припущеннями.
- Перед завершенням змін запускай `swift build` і `swift test`, якщо toolchain доступний; якщо ні — чітко повідом про обмеження.
- Не змінюй призначення курсу: спочатку основи мови й кросплатформні приклади, потім Xcode та SwiftUI на Mac.
