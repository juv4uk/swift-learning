# Інструкції для AI-агентів

- Пояснюй навчальний матеріал українською мовою.
- Використовуй ідіоматичний Swift і зрозумілі англомовні ідентифікатори в коді.
- Цільовий toolchain курсу: Swift 6.4.2+; Package.swift використовує tools-version 6.0 для сумісності.
- Основний курс має бути кросплатформним для Windows, Linux і macOS; не додавай залежність від Apple SDK до спільних уроків.
- Xcode та SwiftUI розглядай як окремий додатковий напрям, доступний на macOS.
- Не додавай сторонні пакети без необхідності.
- Кожен приклад має бути самодостатнім і містити команди запуску для відповідних оболонок.
- Не замінюй реальні результати тестів припущеннями.
- Перед завершенням змін запускай `swift build` і `swift test`, якщо toolchain доступний; якщо ні — чітко повідом про обмеження.
