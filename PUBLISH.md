# Робота з GitHub

Віддалений репозиторій: https://github.com/juv4uk/swift-learning

Клонувати:

```bash
git clone https://github.com/juv4uk/swift-learning.git
cd swift-learning
```

Після змін:

```bash
git add .
git commit -m "learn: complete lesson 1 exercises"
git push
```

Не додавай до Git згенеровану директорію `.build/` або виконувані файли з `build/`.
