# Урок 1. Перші рядки Swift

## Мета

Навчитися запускати програму, оголошувати константи й змінні та виводити текст.

## Що ти вивчиш і навіщо

Після уроку ти зможеш:

- відрізняти значення, які не змінюються, від значень, які змінюються;
- читати простий Swift-код зверху вниз;
- виводити текст і числа за допомогою `print`;
- вставляти значення змінних у повідомлення;
- самостійно знайти й виправити кілька типових помилок компілятора.

Це основа майже кожної програми. Перш ніж рахувати, працювати з файлами чи будувати інтерфейс, програмі потрібно зберегти дані та повідомити результат.

## Ключові поняття

- `let` — значення, яке після ініціалізації не можна змінити.
- `var` — змінна, якій можна присвоювати нові значення.
- `String` — текст; `Int` — цілі числа; `Double` — числа з дробовою частиною; `Bool` — `true` або `false`.
- Інтерполяція `\(value)` вставляє значення в рядок.
- Swift часто сам визначає тип за початковим значенням. Це називається type inference.
- `print(...)` — стандартна функція, яка виводить передане значення в консоль. Консоль — це область, де видно текстовий результат запуску програми.
- Оголошення — створення імені для значення. Наприклад, `let name = "Володимир"` оголошує константу `name`.
- Присвоєння — запис нового значення у змінну. Оператор `+=` додає число до поточного значення: `minutes += 15` означає `minutes = minutes + 15`.

## Приклад

```swift
let name = "Володимир"
var lessonsCompleted = 0

print("Привіт, \(name)!")
lessonsCompleted += 1
print("Завершено уроків: \(lessonsCompleted)")
```

## Покроковий розбір коду

1. `let name = "Володимир"` створює константу `name`. Swift бачить текст у лапках і визначає тип `String`.
2. `var lessonsCompleted = 0` створює змінну з цілим числом. Оскільки використано `var`, це значення можна змінити.
3. Порожній рядок не впливає на виконання. Він лише відділяє логічні частини коду та полегшує читання.
4. `print("Привіт, \(name)!")` виводить рядок. Частина `\(name)` замінюється поточним значенням `name`, тому результатом буде `Привіт, Володимир!`.
5. `lessonsCompleted += 1` збільшує лічильник з `0` до `1`. Це можливо, бо `lessonsCompleted` — змінна, а не константа.
6. Другий `print` вставляє вже нове значення лічильника.

Очікуваний результат:

```text
Привіт, Володимир!
Завершено уроків: 1
```

Зверни увагу: лапки потрібні, коли ми записуємо текст як `String`. Число `42` і текст `"42"` виглядають схоже, але це різні типи, тому Swift не вважає їх одним і тим самим значенням.

## Як думати над задачею

Коли отримуєш маленьку задачу, не починай одразу з усього коду. Розклади її на питання:

1. Які дані потрібні? Наприклад, ім'я — це `String`, кількість уроків — `Int`.
2. Які дані не змінюються? Для них обирай `let`.
3. Які дані змінюються під час роботи? Для них обирай `var`.
4. Яку дію треба виконати? Наприклад, збільшити лічильник на `1`.
5. Що саме треба побачити в результаті? Додай для цього `print`.

Якщо програма не запускається, спочатку прочитай перший рядок помилки та подивися на вказаний рядок коду. Не намагайся виправляти кілька речей навмання одночасно.

Windows / PowerShell:

```powershell

```

Linux / macOS:

```bash
./scripts/run-example.sh 01-hello
./scripts/run-example.sh 02-values
./scripts/run-example.sh 03-conditions-loops
```

На Windows скрипт компілює код через `swiftc`, тому не потрібно запускати окремий файл через JIT-команду `swift main.swift`. Якщо виникають проблеми з бібліотеками toolchain, дивись [інструкцію Windows](../docs/SETUP-WINDOWS.md). Спільні команди для всіх уроків зібрані в [довіднику платформ](../docs/PLATFORM-GUIDE.md).

Скрипт запуску — це підготовлена команда, яка знаходить приклад, передає його компілятору Swift і запускає отриману програму. Тобі не потрібно знати всі внутрішні кроки, але важливо розрізняти два етапи: компілятор перевіряє код, а потім програма виконується. Повідомлення про помилку компіляції означає, що програму ще треба виправити.

## Практичне завдання: лічильник навчання

Створи власний короткий звіт про навчання. Виконуй кроки послідовно й запускай програму після кожної суттєвої зміни:

1. Скопіюй приклад у новий файл або використай файл вправи.
2. Заміни `"Володимир"` на своє ім'я.
3. Додай `let targetHours: Double = 10.0` — цільову кількість годин. Явний тип після двокрапки показує Swift, що це `Double`.
4. Створи `var minutes = 30` і збільш його на `15` через `minutes += 15`.
5. Виведи повідомлення з поточним значенням `minutes`.
6. Перевір, що `targetHours` не змінюється, а `minutes` змінюється.
7. Прочитай результат у консолі та поясни вголос, звідки взялося кожне число.

Один можливий короткий фрагмент для кроків 3–5:

```swift
let targetHours: Double = 10.0
var minutes = 30
minutes += 15

print("Ціль: \(targetHours) годин")
print("Навчання сьогодні: \(minutes) хвилин")
```

## Вправи

1. Заміни ім'я на своє та запусти програму.
2. Додай константу `targetHours` типу `Double`.
3. Створи змінну `minutes`, збільш її на 15 і виведи результат.
4. Спробуй змінити `let` після оголошення. Прочитай помилку компілятора й поясни її своїми словами.

## Типові помилки

### Спроба змінити `let`

```swift
let name = "Оля"
name = "Іра"
```

Причина: `let` створює незмінну константу. Якщо значення справді має змінюватися, оголоси його через `var`:

```swift
var name = "Оля"
name = "Іра"
```

### Пропущені лапки в тексті

```swift
let greeting = Привіт
```

Причина: Swift сприймає `Привіт` як ім'я, а не як текст. Для `String` потрібні подвійні лапки:

```swift
let greeting = "Привіт"
```

### Невідповідні типи

```swift
let count = 42
print("Кількість: " + count)
```

Причина: оператор `+` тут намагається поєднати текст і число. Використай інтерполяцію:

```swift
let count = 42
print("Кількість: \(count)")
```

### Неправильне ім'я змінної

```swift
let studentName = "Оля"
print(studentname)
```

Причина: імена чутливі до регістру. `studentName` і `studentname` — різні імена. Виправ виклик так, щоб написання збігалося:

```swift
print(studentName)
```

## Самоперевірка

- Чим `let` відрізняється від `var`?
- Чому `"42"` і `42` — різні значення?
- Що робить `\(name)` усередині рядка?
- Що виведе приклад після `lessonsCompleted += 1`?
- Коли варто явно написати тип `Double`?
- Чому помилку зміни `let` треба виправляти зміною оголошення, а не синтаксисом присвоєння?

Ти готовий перейти далі, якщо можеш без підказки написати маленьку програму з одним `let`, одним `var`, операцією `+=` та двома `print`, пояснити тип кожного значення й самостійно виправити помилку в імені змінної або спробу змінити `let`.
