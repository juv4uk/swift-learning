# Урок 2. Функції, колекції та Optional

## Мета

Розбити програму на невеликі функції, зберігати набори значень і безпечно працювати з відсутніми даними.

## Функції

Функція має ім'я, параметри та, за потреби, тип результату:

```swift
func greeting(for name: String) -> String {
    "Привіт, \(name)!"
}
```

У Swift зовнішні імена параметрів є частиною читабельного виклику: `greeting(for: "Оля")`.

## Колекції

- `Array` зберігає впорядкований список.
- `Dictionary` зберігає пари ключ-значення.
- `Set` зберігає унікальні значення без гарантованого порядку.

## Optional

Словник може не містити запитаного ключа. Тому результат пошуку має тип `Int?`, а не просто `Int`:

```swift
let minutesByTopic = ["Функції": 45]
if let minutes = minutesByTopic["Функції"] {
    print(minutes)
}
```

`if let` розпаковує Optional лише тоді, коли значення існує. `??` задає безпечне значення за замовчуванням.

## Вправи

1. Напиши `func square(_ number: Int) -> Int`.
2. Створи масив із п'яти тем і виведи їх через `for-in`.
3. Створи словник із назвами тем і хвилинами навчання.
4. Запитай у словника відсутній ключ і оброби `nil` через `if let` або `??`.
5. Створи `Set` із повторюваними рядками та перевір кількість елементів.
