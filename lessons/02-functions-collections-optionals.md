# Урок 2. Функції, колекції та Optional

## Що ти вивчиш і навіщо

У цьому уроці ти навчишся:

- оформлювати повторювану дію як **функцію**;
- зберігати кілька значень у `Array`, `Dictionary` і `Set`;
- розуміти, чому деякі значення в Swift можуть бути відсутніми (`Optional`);
- безпечно діставати значення зі словника й не припускатися помилок через `nil`.

Ці інструменти потрібні майже в кожній програмі. Функції допомагають не дублювати код, колекції дають змогу працювати зі списками й наборами даних, а `Optional` змушує чесно враховувати ситуації, коли потрібного значення немає.

## Функції

Функція — це іменований блок коду для окремої дії. Її можна викликати скільки завгодно разів. Функція має ім'я, параметри та, за потреби, тип результату:

```swift
func greeting(for name: String) -> String {
    "Привіт, \(name)!"
}

let message = greeting(for: "Оля")
print(message)
```

### Розбір прикладу крок за кроком

1. `func` повідомляє Swift, що ми оголошуємо функцію.
2. `greeting` — ім'я функції.
3. `for name: String` — параметр: під час виклику сюди передається рядок. `for` — зовнішнє ім'я, яке робить виклик зрозумілішим.
4. `-> String` означає: функція повертає значення типу `String`.
5. Рядок у фігурних дужках — тіло функції. Останній вираз є результатом, тому тут не обов'язково писати `return`.
6. `greeting(for: "Оля")` викликає функцію, а повернений текст зберігається в `message`.

У Swift зовнішні імена параметрів є частиною читабельного виклику: `greeting(for: "Оля")`. Якщо зовнішнє ім'я не потрібне, перед параметром ставлять `_`:

```swift
func square(_ number: Int) -> Int {
    number * number
}

print(square(4)) // 16
```

Тут `number` — локальне ім'я всередині функції, а `_` означає, що під час виклику мітку `number` писати не треба.

### Як думати над задачею про функцію

Спочатку сформулюй дію одним реченням: «Функція отримує число й повертає його квадрат». Потім визнач:

1. які дані потрібні на вході та їхній тип;
2. який результат має бути на виході та його тип;
3. яку найменшу дію треба виконати в тілі функції;
4. як перевірити результат на простому прикладі.

## Колекції

Колекція зберігає кілька значень. Вибір колекції залежить від того, як ти плануєш шукати й використовувати дані:

- `Array` зберігає впорядкований список. Елементи мають позиції, які починаються з `0`.
- `Dictionary` зберігає пари ключ-значення. За ключем можна знайти пов'язане значення.
- `Set` зберігає унікальні значення без гарантованого порядку.

Короткий приклад усіх трьох типів:

```swift
let topics = ["Функції", "Масиви", "Optional"]
print(topics[0])

let minutesByTopic = ["Функції": 45, "Optional": 30]
print(minutesByTopic["Функції"] as Any)

let tags: Set = ["swift", "swift", "beginner"]
print(tags.count) // 2
```

Масив підходить, коли важливі порядок і позиція. Словник зручний, коли є зрозумілий ключ, наприклад назва теми. Множина підходить для перевірки унікальності: повторне значення не створює нового елемента.

## Optional

`Optional` — це значення, якого може не бути. Запис `Int?` означає «або ціле число, або `nil`». `nil` — спеціальне значення «нічого немає»; це не те саме, що `0` або порожній рядок.

Словник може не містити запитаного ключа. Тому результат пошуку має тип `Int?`, а не просто `Int`:

```swift
let minutesByTopic = ["Функції": 45]
if let minutes = minutesByTopic["Функції"] {
    print(minutes)
}
```

### Що відбувається під час пошуку

1. Swift шукає ключ `"Функції"` у словнику.
2. Якщо ключ є, результат містить число `45`.
3. Якщо ключа немає, результатом буде `nil`.
4. `if let` перевіряє Optional і створює звичайну константу `minutes` лише тоді, коли число існує.

Для значення за замовчуванням використовуй `??`:

```swift
let minutesByTopic = ["Функції": 45]
let minutes = minutesByTopic["Мережа"] ?? 0
print(minutes) // 0
```

Тут, якщо ключа `"Мережа"` немає, програма використовує `0`. Оператор `??` не прибирає проблему мовчки: він явно задає запасний варіант.

### Типові помилки

- **Спроба використати `Int?` як `Int`.** Наприклад, `let total = minutesByTopic["Функції"] + 10` не компілюється, бо пошук може повернути `nil`. Використай `if let` або `??`.
- **Звертання до неіснуючого індексу масиву.** `topics[10]` може завершити програму з помилкою. Перевір кількість елементів або перебирай масив через `for-in`.
- **Очікування порядку від `Set`.** Не покладайся на позиції елементів множини. Якщо порядок важливий, використовуй `Array`.
- **Плутанина між ключем і значенням словника.** У `"Функції": 45` ключ — `"Функції"`, а значення — `45`; шукати треба за ключем.
- **Забутий зовнішній ідентифікатор параметра.** Для `greeting(for:)` правильний виклик — `greeting(for: "Оля")`, а не `greeting("Оля")`.

Виконай завдання послідовно, щоб побачити різницю між колекціями та безпечною роботою з даними:

1. Напиши `func square(_ number: Int) -> Int` і перевір її для `4` та `-3`.
2. Створи масив із п'яти тем і виведи їх через `for-in`.

Перед написанням коду назви колекції вголос: «мені потрібен порядок», «мені потрібен пошук за ключем» або «мені потрібні лише унікальні значення». Це допомагає обрати тип не навмання.
