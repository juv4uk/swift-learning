# Урок 3. Власні типи: struct, class, enum

## Мета

Навчитися описувати предметну область власними типами.

## `struct`

Структура групує пов'язані дані та поведінку. Зазвичай це добрий початковий вибір для моделі значення:

```swift
struct Programmer {
    let name: String
    var experience: Int

    func introduce() {
        print("Привіт! Я \(name).")
        print("Досвід: \(experience) років.")
    }
}
```

`let` у властивості означає, що її не можна змінити після створення екземпляра. `var` дозволяє змінювати властивість, якщо сам екземпляр оголошений через `var`.

## `enum`

Перелічення описує скінченний набір станів:

```swift
enum StudyStatus {
    case planned, inProgress, completed
}
```

`switch` має розглянути всі можливі варіанти enum.

## `class`

Класи мають reference semantics: змінні можуть посилатися на той самий екземпляр. У структурах значення копіюється при присвоєнні (із оптимізаціями copy-on-write для багатьох стандартних колекцій).
