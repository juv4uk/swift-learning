# Урок 4. Протоколи, extensions і generics

## Мета

Описувати спільну поведінку без непотрібної ієрархії класів.

## Протокол

Протокол задає вимоги, які має виконати тип:

```swift
protocol Describable {
    var summary: String { get }
}
```

Тип може відповідати кільком протоколам. Це дозволяє комбінувати можливості.

## Extension

`extension` додає обчислювані властивості або методи до наявного типу, не змінюючи його початкове оголошення.

## Generics

Узагальнення дозволяють писати функції для різних типів, якщо вони виконують спільну вимогу:

```swift
func printSummary<T: Describable>(of value: T) {
    print(value.summary)
}
```

`T: Describable` означає, що `T` має відповідати протоколу `Describable`.

## Запуск прикладу
