# Урок 6. ARC та конкурентність

## ARC

Swift використовує Automatic Reference Counting для керування пам'яттю екземплярів класів. Сильні посилання утримують екземпляр живим. Цикл сильних посилань може не дозволити звільнити пам'ять.

- `weak` — слабке посилання, яке автоматично стає `nil` після звільнення об'єкта.
- `unowned` — посилання без утримання; його можна читати лише поки об'єкт гарантовано існує.

Починай із `weak` там, де життєвий цикл не гарантований.

## async/await

`async` позначає асинхронну функцію, `await` — місце, де виконання може призупинитися, очікуючи результат.

```swift
func loadTitle() async -> String {
    "Перший асинхронний урок"
}

let title = await loadTitle()
```

## Task і actor

`Task` запускає асинхронну роботу. `actor` ізолює змінний стан, щоб конкурентні задачі не змінювали його неконтрольовано.

Не плутай асинхронність із паралельністю: `async/await` описує роботу з операціями, що можуть призупинятися; фактичне планування залежить від runtime та executor.

## Запуск асинхронного прикладу

Windows / PowerShell:

```powershell
.\scripts\run-example.ps1 08-errors-async
```

Linux / macOS:

```bash
./scripts/run-example.sh 08-errors-async
```

Скрипти додають `-parse-as-library`, потрібний для прикладу з `@main`. ARC, `async/await` і `actor` — частина Swift і доступні для вивчення на Windows та Linux.

## Вправи

4. Створи actor, який зберігає лічильник, і безпечно змінюй його з кількох Task.
