## Мета
Завершити першу частину курсу: створити кросплатформний консольний Study Tracker, логіка та модель якого стануть основою майбутнього macOS-застосунку на SwiftUI.

## Вимоги до функціональності
- [ ] StudyItem зі стабільним ID (UUID), назвою, статусом і датою створення.
- [ ] StudyStatus як enum: planned, inProgress, completed.
- [ ] Додавання, редагування статусу, пошук за ID та фільтрація.
- [ ] Перевірка порожньої/некоректної назви.
- [ ] JSON persistence через Foundation URL/FileManager.
- [ ] Обробка відсутнього файла, пошкодженого JSON і відсутнього запису.
- [ ] Автоматичні тести моделі, бізнес-правил і сховища.
- [ ] README з інструкцією збірки, запуску та архітектурою.

## Послідовність
1. Спроєктуй модель і статуси.
2. Реалізуй бізнес-правила окремо від консольного меню.
3. Напиши тести.
4. Додай JSON-сховище.
5. Створи просте CLI-меню.
6. Перевір чисту збірку та всі тести.

## Кросплатформність
Основний код не повинен залежати від Apple SDK або SwiftUI. Перевіряй його на своїй ОС; якщо заявляєш підтримку іншої ОС, спочатку реально запусти там build і tests.
