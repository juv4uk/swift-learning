Ці інструменти часто зустрічаються в реальних програмах: наприклад, щоб перетворити список цін, відфільтрувати результати пошуку або перевірити введене ім’я до подальшої роботи з ним.

## Closures: поведінка, яку можна передати

**Closure** — це блок коду, який можна зберегти у змінній або передати функції. Він схожий на функцію без обов’язкової назви. Closure також може використовувати значення з навколишнього коду — це називається захопленням значення.

```swift
let doubled = [1, 2, 3].map { number in
    number * 2
}

print(doubled) // [2, 4, 6]
```

Як читати цей приклад:

1. `[1, 2, 3]` — початковий масив.
2. `map` по черзі передає кожне число в closure.
3. `number` — поточний елемент.
4. Вираз `number * 2` — нове значення для цього елемента.
5. `map` повертає **новий** масив і не змінює початковий.

Ключове слово `in` відділяє список параметрів closure від його тіла. У коротших прикладах Swift може скоротити запис:

```swift
let doubled = [1, 2, 3].map { $0 * 2 }
```

Тут `$0` означає перший параметр closure. На початку навчання форма з `number in` часто зрозуміліша, а коротку форму зручно читати після практики.

## Основні операції над масивом

- `map` перетворює кожен елемент і повертає масив результатів.
- `filter` залишає елементи, для яких closure повертає `true`.
- `sorted` повертає впорядковану копію масиву.
- `reduce` зводить послідовність до одного результату.

```swift
let numbers = [5, 2, 8, 1]

let squares = numbers.map { number in
    number * number
}

let evenNumbers = numbers.filter { number in
    number % 2 == 0
}

let ascending = numbers.sorted { left, right in
    left < right
}

let total = numbers.reduce(0) { partialResult, number in
    partialResult + number
}

print(squares)      // [25, 4, 64, 1]
print(evenNumbers)  // [2, 8]
print(ascending)    // [1, 2, 5, 8]
print(total)        // 16
```

### Як думати над задачею

Спершу визнач, **який результат потрібен**:

- «Для кожного елемента зробити інше значення» → `map`.
- «Залишити тільки ті, що підходять» → `filter`.
- «Розкласти за порядком» → `sorted`.
- «Отримати одне число або інше одне значення» → `reduce`.

Потім опиши словами, що має зробити closure з одним елементом. Наприклад: «для кожного числа перевірити, чи воно парне». Тільки після цього записуй умову Swift. Це допомагає не плутати `map` і `filter`: `map` створює нові значення, а `filter` повертає або відкидає старі.

## Обробка помилок

Функція з `throws` може повідомити про помилку замість того, щоб повернути звичайний результат. Її виклик позначається `try`, а результат обробляється через `do-catch` або передається далі іншій функції, яка теж має `throws`.

Спочатку оголосимо власний тип помилки та функцію перевірки:

```swift
enum InputError: Error {
    case emptyName
}

func validate(name: String) throws {
    guard !name.isEmpty else {
        throw InputError.emptyName
    }
}
```

Покроковий розбір:

1. `enum InputError: Error` описує можливі помилки цієї задачі.
2. `emptyName` означає, що ім’я порожнє.
3. `throws` у заголовку функції попереджає: виклик може завершитися помилкою.
4. `guard` перевіряє умову, яка має бути правдивою для продовження.
5. `throw InputError.emptyName` негайно повідомляє про проблему.

Саме слово `throws` не обробляє помилку автоматично. Обробник можна написати так:

```swift
func checkName(_ name: String) {
    do {
        try validate(name: name)
        print("Ім’я прийнято: \(name)")
    } catch InputError.emptyName {
        print("Помилка: ім’я не може бути порожнім")
    } catch {
        print("Інша помилка: \(error)")
    }
}

checkName("Олена")
checkName("")
```

`do` містить операції, які можуть завершитися помилкою. `try` ставиться перед викликом `validate`. Якщо помилки немає, виконується наступний рядок. Якщо помилка виникла, Swift переходить до відповідного `catch` і не виконує решту коду в `do`.

### Інші форми `try`

- `try? validate(name: name)` перетворює помилку на `nil`. Це зручно, коли достатньо знати «вдалося чи ні», але не потрібно пояснення.
- `try! validate(name: name)` вимикає безпечну обробку. Якщо помилка виникне, програма аварійно завершиться, тому для введення користувача цей варіант не підходить.

Для навчальних і користувацьких сценаріїв зазвичай починай із `do-catch`: так ти не втрачаєш причину помилки.

## Типові помилки

### Використати `map`, коли потрібно лише відфільтрувати

**Проблема:** `numbers.map { $0 % 2 == 0 }` повертає `[Bool]`, а не масив парних чисел.

**Причина:** `map` замінює кожен елемент результатом closure.

**Виправлення:** використай `filter { $0 % 2 == 0 }`.

### Забути `try`

**Проблема:** виклик `validate(name: name)` не компілюється.

**Причина:** Swift вимагає явно позначити місце, де може виникнути помилка.

**Виправлення:** виклич функцію всередині `do` як `try validate(name: name)` і додай `catch`.

### Переплутати `throw` і `throws`

`throws` пишеться в оголошенні функції й означає «функція може кинути помилку». `throw` пишеться всередині функції в конкретному місці, де помилка виникла.

### Вважати, що `sorted` змінює початковий масив

`sorted` повертає новий масив. Якщо потрібно зберегти результат, запиши його в змінну, наприклад `let ascending = numbers.sorted { $0 < $1 }`.

## Запуск власного прикладу

Фрагменти цього уроку скопіюй у файл `main.swift`, додай виклики функцій і скомпілюй. Команда `swiftc` — компілятор Swift: він перетворює файл програми на виконуваний файл. Папка `build` потрібна лише для зручного зберігання результату компіляції.

Windows / PowerShell:

```powershell
New-Item -ItemType Directory -Force build | Out-Null
swiftc .\main.swift -o .\build\lesson05.exe
.\build\lesson05.exe
```

Linux / macOS:

```bash
mkdir -p build
swiftc ./main.swift -o ./build/lesson05
./build/lesson05
```

Якщо компілятор покаже помилку, прочитай рядок і позицію в повідомленні. Часто проблема в пропущеній дужці, неправильному імені змінної або відсутньому `try`.
