# Урок 7. Пакети, тести та JSON

## Swift Package Manager

`Package.swift` описує пакет: продукти, цілі, залежності та платформи. Ціль може бути бібліотекою, виконуваною програмою або тестами.

Основні команди:

```bash
swift build
swift run
swift test
```

## Модулі та доступ

`import` підключає модуль. `public` відкриває API для інших модулів; без модифікатора оголошення зазвичай доступне лише в межах модуля (`internal`). Не відкривай усе без потреби.

## Codable

Типи, що відповідають `Codable`, можна кодувати й декодувати, наприклад у JSON. Дані ззовні потрібно вважати ненадійними: декодування може завершитися помилкою.

## Тестування

Тест має перевіряти поведінку, а не внутрішню реалізацію. Назва тесту описує сценарій, assertion — очікуваний результат.

## Вправи

1. Додай тип `StudyItem` із `Codable`.
2. Закодуй його в JSON і декодуй назад.
3. Додай тест, що перевіряє збереження значень після round-trip.
4. Додай тест на некоректний JSON.
5. Запусти `swift test` і переконайся, що бачиш зрозумілий результат.
